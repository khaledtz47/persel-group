# Persel Codex handoff

This package prepares a rebuild; it does not contain a website implementation. The original supplied references are preserved in references/. The adapted specification is design-direction.md; keep Vanta's original Markdown as a reference only.

## Use

Start a new Codex conversation in a separate project folder or an appropriate rebuild branch. Copy this package's files into the build workspace. Add the logo, photography and local font files when available. Keep the original site/build separately. Review global/project instructions for stale context rather than relying on a "forget everything" prompt.

Read content-brief.md first, then design-direction.md. Both distinguish source material from recommendations. This is a working handoff, not a claim that all copy, service detail or detailed service routes are approved. Separate /hiring and /executives audience pages are approved.

Before coding, confirm your understanding of the homepage sequence, the two audience journeys, and which content remains missing. Ask only about decisions that materially block implementation. Separate /hiring and /executives pages are approved. Link "I'm Hiring" to /hiring and "I'm an Executive" to /executives. Do not ask for this decision again or substitute homepage tabs.

Then implement the homepage first in the authorized stack. Use source-supported content and clearly identified temporary assets where necessary. Do not invent evidence or detailed service claims. Review the actual browser output at desktop and mobile widths, fix layout issues, and report build validation. Pause for homepage design review before expanding the design across remaining pages. Do not deploy.
